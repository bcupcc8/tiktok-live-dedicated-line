## 为什么直播专线看IP，不看带宽

1080P推流的码率通常在 3–6Mbps，一台标称 50Mbps 的机器跑单个直播间绰绰有余，带宽从来不是瓶颈。卡顿、限流、0播放这些问题，多数出在IP属性上。

三个概念要分清。原生IP指IP归属地和服务器所在地一致，没有经过转发伪装；住宅IP指IP来自当地宽带运营商，而不是机房托管段；双ISP指检测工具里能看到两条家庭宽带属性。三者叠加的“双ISP住宅原生IP”是这类直播VPS卖得最贵的一档，因为它最接近平台眼里“一个当地人在家上网”的样子。

普通机房IP被平台识别成数据中心流量，推流质量会被压制，这是行业里普遍认可的逻辑，具体压到什么程度各家说法不一，也没有公开可查的官方规则。能确定的是，WePC 这批套餐全部标注原生家宽或双ISP IP，没有纯机房IP的低价款，选型时不用再纠结这一层。

带宽方面真正要看的不是峰值数字，是流量额度和超量后的处理方式，后面限制那一节会讲。

## 三条容易被忽略的限制

**超流量会限速。** 马来西亚套餐页明确写了“超流量限速5M”，其余套餐基本是 2TB 双向流量封顶。按 1080P 每小时约 2GB 的上传量算，2TB 够连续播几百小时，正常节奏用不完；但如果是24小时挂机或者多设备共用，就要盯着后台流量。超了不会断线，会掉到 5Mbps，推流码率顶不住就开始卡。

**部分节点有协议兼容问题。** 台区这类热门节点曾出现过对 Shadowsocks 协议的限制说明，下单前发个工单问清楚你的搭建方式能不能跑，比开通后再退省事。WePC 各套餐对代理协议的支持不完全一致，以官方回复为准。

**一台机器对应一个直播号。** 平台的风控逻辑是账号、IP、设备三者关联，同一IP挂多个直播号容易触发关联。养号阶段可以适当放宽，直播建议一号一机。想多号并行的，成本要按倍数算，别按一台机器的价格估预算。

另外，美国9929、日本这类优化线路是回程优化，和“国内直连”不是一回事；新加坡IDC、马来西亚、韩国联通方向都需要中转，下单时把中转成本一起算进去。

## 什么时候该上独享专线

需要专线的场景很清楚：多机位同时开播、账号矩阵要跑十几台设备、直播时长极端到按天算。这种规模下，一台VPS一台机器的月成本乘上去，反而不如直接买带宽独享的专线省心。

单账号、日播几小时的中小卖家，用 WePC 这类原生家宽VPS就够，多花的钱买不到对应的直播效果。反过来，团队规模已经超过三台设备，还在用低价VPS拼凑，卡顿和关联风险的成本会比专线贵。
